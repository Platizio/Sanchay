**One conflict needs the lead to see it.** The owner's rename rules keep four hosts: www, app, ops and api (`*.sanchay.in`). GAP-06 §4 instead says to delete `app.sanchay.in` and serve the web app at the apex. Because owner rules rank above gap-fill rulings, D-PLATFORM-010 keeps the four-host model. It keeps what GAP-06 was protecting: a verified `/app/*` link namespace, HTTPS callbacks, and no custom scheme in production. This is listed as OPEN item O-01 for confirmation; D-PLATFORM-010 is binding until then.
